# 手工测试用例设计

| 用例编号 | 输入A | 运算符 | 输入B | 预期结果 | 测试类型 |

| ADD_001 | 3 | + | 5 | 8 | 正常等价类 |
| ADD_002 | 0 | + | 5 | 5 | 边界值 |
