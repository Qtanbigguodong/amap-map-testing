# 缺陷清单

## Bug #001: 刚启动程序直接点击"="导致崩溃

- **严重程度**: 严重
- **复现步骤**:
  1. 打开计算器程序
  2. 不输入任何数字，直接点击"="
- **预期结果**: 提示"请输入数字"或不做任何响应
- **实际结果**: 程序崩溃退出
- **根因分析**: Recording变量为null时未做判空处理
- **状态**: 已修复

## Bug #002: 连续点击"="结果不累加

- **严重程度**: 一般
- **复现步骤**:
  1. 输入 "1+1"，点击"=" → 显示2
  2. 再次点击"=" → 预期显示3，实际仍显示2
- **根因分析**: 连续等号时未将当前结果赋给NumberA
- **状态**: 已修复

## Bug #003: 清空后点击"="仍显示旧结果

- **严重程度**: 一般
- **复现步骤**:
  1. 输入 "1+1"，点击"=" → 显示2
  2. 点击清空
  3. 再次点击"=" → 预期无响应，实际仍显示2
- **根因分析**: 清空按钮未清空Recording状态变量
- **状态**: 已修复
